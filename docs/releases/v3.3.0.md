# depxray v3.3.0

This release makes the browser dependency graph substantially easier to read and navigate, especially for larger projects.

## Highlights

- Six focused graph presets: Overview, Direct relationships, Full neighborhood, Circular dependencies, Architecture violations, and High-impact files.
- Automatic Project, Folder, and File scopes when navigating the project tree.
- Stable layouts tailored to each scope, including a Dependents → Selected → Dependencies file view.
- An 80-node initial rendering budget with drillable folder grouping for larger neighborhoods.
- Semantic labels that prioritize important nodes and become smaller at close zoom.
- Hover and selection focus that fades unrelated nodes and edges.
- Quieter directional arrows plus optional type-only and dynamic dependency edges.
- A clearer Center view control for switching between Graph, Miller, and Dashboard.
- Normal-weight project-tree labels and a corrected README architecture flowchart.

## Validation

- `npm run verify`: lint, formatting, type checks, production builds, and 219 unit/integration tests
- Five responsive Chromium end-to-end tests covering desktop, tablet, and phone layouts
- CI configured to repeat quality checks on Node.js 18, 20, and 22
- npm package-content inspection for the CLI, Core, and MCP packages

## Install

```bash
npx depxray@3.3.0 scan
```

For MCP-compatible clients:

```bash
npx --package @depxray/mcp@3.3.0 depxray-mcp
```

## Upgrade notes

This release has no configuration or graph-payload breaking changes. Type-only and dynamic graph edges now start hidden in the browser UI; users can enable either edge category from the graph controls.
